# 手动测试清单 — Phase 10 附着(文件/选区)

> 配合 `node apps/vscode/scripts/smoke-shell.mjs`(自动化部分,模拟拖放/chip)+ 本清单
> (需 VS Code 交互的真机验证)。前置:3080 在线;扩展宿主已启动(双击 `启动扩展.command`);
> 工作区打开一个含多个文件的目录。

## 1. Explorer 原生拖入(需求 1,核心)

- [ ] 从 VS Code Explorer 拖 1 个文件到对话输入区 → 拖入过程中输入区出现高亮遮罩
- [ ] drop 后输入区上方出现「文件名 (大小) ×」chip;可点击 × 移除
- [ ] 连续拖多个文件(可混合不同目录)→ 全部成为 chip,顺序保持
- [ ] 重复拖同一文件 → 不重复添加(去重)
- [ ] 拖入文件夹 → 出现错误 toast「目录暂不支持」,不添加 chip
- [ ] 发送消息 → 模型可见附着文件内容(带 `<attachments>` 块,文件名/路径/fence 正文)
- [ ] 附件发送后 chip 仍在(可继续携带下一次消息);移除 chip 后再发送则不再携带
- [ ] 工作区外文件(如 /tmp/foo.ts)拖入 → chip 带警告样式(工作区外),发送含警告标注
- [ ] 大文件(>1 MiB,如一个大 log)拖入 → chip 正常,发送时正文被「too-large」标注替代
- [ ] 二进制文件(如 .png/.bin)拖入 → 发送时正文被「binary file」标注替代(不注入乱码)
- [ ] 拖入不干扰上游输入:拖放后 textarea 仍可聚焦、回车发送正常;发送中的流式输出不会清掉 chip

## 2. 附着活动文件(需求 2)

- [ ] 输入区上方出现「附着文件」开关 chip;默认关闭
- [ ] 点击开关 → 变亮(accent 色);VS Code 设置 `deepseekHarness.context.attachActiveFile` 同步为 true
- [ ] 开启后 chip 文案显示当前文件(如「附着文件: src/foo.ts」),切换活动编辑器实时更新
- [ ] 修改文件不保存(isDirty)→ 开关文案带未保存标记;发送后模型收到的是**含未保存改动的** buffer 内容
- [ ] 无活动编辑器(关闭所有编辑器)→ 开关变为禁用态;发送时不注入该块,不报错
- [ ] untitled 文件(新建未保存)→ 可附着,发送的是当前 buffer 内容
- [ ] 关闭开关或改设置 → 发送不再携带文件正文(但 file/language 元数据行仍注入)
- [ ] 大文件开启附着 → 正文按 20k 截断,带截断标注

## 3. 附着活动选区(需求 3)

- [ ] 「附着选区」开关默认关闭;点击开启后 chip 显示当前选区行号(如「附着选区: 3-5」)
- [ ] 拖选/点击改变选区 → chip 行号实时更新(50ms 防抖);多光标选区显示全部范围
- [ ] 清空选区 → 开关变禁用态;再选中恢复
- [ ] 发送后模型收到 `<selection index range=…>` 块(1-based 行列 + fenced 文本)
- [ ] 选区 >20k 字符 → 截断并标注
- [ ] 两个开关同时开启 → 同一 `<editor-context>` 块内 selection + full-file 并存;
      全选整个文件时只发 full-file(去重,不重复发 selection)
- [ ] 附着开关与拖入文件可同时使用:editor-context 块 + attachments 块都注入

## 4. 命令与设置

- [ ] 命令面板 `DeepSeek Harness: 切换附着活动文件` / `切换附着选中内容` 可切换开关
- [ ] 设置页直接改 `context.attachActiveFile` / `context.attachSelection` → 输入区 chip 状态同步
- [ ] 重启扩展后开关状态保留(设置持久化)

## 5. 稳定性与回归

- [ ] 会话切换/新建会话后附着 UI 仍在输入区上方(注入不丢)
- [ ] 进入会话管理页再返回 → 附着 UI 正确隐藏/恢复,不残留
- [ ] 连续发送多轮消息(流式输出)→ chip 不被上游重渲染清除
- [ ] 深色/浅色主题下 chip/遮罩/toast 可读
- [ ] 原有回归:返回按钮、会话管理页、语言切换均正常(本特性不破坏既有注入)

## 已知限制(Phase 10 边界)

- OS 桌面/访达拖入为二级支持:能取到路径(webUtils)则附着,否则 toast 提示「请从 Explorer 拖入」
- 目录附着/递归展开不在本期(拒绝并提示)
- 附着内容上限:单文件 20k 字符、单次 16 个、附件总量 100k 字符、>1 MiB 不读正文
- 模型可见性:附件以纯文本块注入(运行时无附件 RPC);model-visible ⟺ logged
